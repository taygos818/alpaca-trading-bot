# Contest Requirements

Source: Alpaca AI Trading Agents Hackathon, August 28 through September 4, 2026.

## Mandatory product requirements

1. Autonomous AI trading agents using Alpaca's Trading API.
2. Meaningful use of Alpaca's MCP server or CLI.
3. Every trading strategy incorporates options.
4. All execution occurs in Alpaca paper trading.

## Submission requirements

- Project title, short description, long description, and technology tags.
- Cover image, video presentation, and slide presentation.
- Public GitHub repository, hosted demonstration, and application URL.
- Original, MIT-compliant submission.

The repository stays private during development. Publication is a gated Milestone 8 action after secret, license, provenance, and history scans pass.
